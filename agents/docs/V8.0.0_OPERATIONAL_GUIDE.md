## Troubleshooting

### Agent Fails to Start

```bash
# Check Python environment
python3 --version
pip list | grep livekit

# Install LiveKit dependencies (if needed)
pip install livekit-agents livekit-agents-openai livekit-plugins-silero

# Run agent with verbose logging
python3 /Volumes/luciaAI/03-knowledge/digital-library/core-agentic-automation/agents/midguyver-agent.py --debug 2>&1 | head -50
```

### Sanskrit Router Connection Fails

```bash
# Verify router is running
curl -v http://localhost:7410/health

# Check IPv6 routing
netstat -rn | grep fd00:741:1

# Verify WebSocket connection
wscat -c ws://localhost:9505

# If offline, restart router:
docker-compose -f /Volumes/luciaAI/03-knowledge/digital-library/docker-compose.yml up -d
```

### High Memory Usage

```bash
# Monitor memory per agent
ps aux | grep agent.py | awk '{print $2, $6}' | sort -k2 -rn

# If exceeding limits in config, adjust:
vim /Volumes/luciaAI/03-knowledge/digital-library/core-agentic-automation/configs/[agent]-config.yaml
# Modify: resources.memory.limits

# Restart affected agent
kill <PID> && python3 [agent-path] &
```
